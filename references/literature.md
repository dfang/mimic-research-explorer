# 文献检索与创新性判断

## 检索顺序

从 draft.md 中列出需验证的临床主张、疾病/暴露/结局定义、已有引文和创新性主张。逐条查其依据，草案参考文献不能默认真实或充分支持结论；把核验结果定位到原文段落。方法学文献用于核查原方案的时间设计、调整策略、预测验证等具体选择，不把一般推荐当成适用于该方案的证明。

先用临床人群、暴露/干预查原始研究，并查指南/综述了解问题；不要先限定 MIMIC。随后加入数据库术语查直接竞争研究，范围先宽后窄，必要时移除结局词避免漏检。精读最相近研究并追踪参考文献和后续研究，兼顾近期论文与早期关键证据，不只查近三年。

PubMed 骨架（替换尖括号，核查搜索翻译及返回记录）：

```text
(<人群同义词 OR 对应 MeSH>) AND (<暴露同义词 OR 对应 MeSH>)
```

组合以下术语块，也用宽词 `MIMIC[tiab]` 补检并人工排除无关语义：

```text
("MIMIC-IV"[tiab] OR "MIMIC IV"[tiab] OR "MIMIC-III"[tiab]
 OR "MIMIC III"[tiab] OR "Medical Information Mart for Intensive Care"[tiab]
 OR "Multiparameter Intelligent Monitoring in Intensive Care"[tiab])
```

MeSH 与标题摘要自由词结合，避免漏掉尚未索引的近期论文。必要时补查出版社、预印本和引用追踪；标记预印本、撤稿、更正，搜索摘要不能代替阅读全文。

## 工具与记录

- 有搜索/浏览工具时直接用；无专门工具但可联网时用 NCBI E-utilities：esearch 获得 PMID，esummary/efetch 核验元数据及摘要。自动请求遵守当时官方速率限制，不为普通检索强求 API key。
- 无联网能力时交付检索式或分析用户给的文献，明确未做实时检索，不伪造 PMID/DOI。
- 每轮记录日期、平台、原样检索式、筛选条件、返回数量（仅平台实际提供时）和实际查看范围。只查看前若干条须说明，不自称系统综述或覆盖全部记录。
- 关键研究记录标题、年份、类型、数据集、人群、暴露及窗口、结局、主要发现和限制，附核验的 PMID/DOI/出版社链接。缺字段写未获得，不猜；按 DOI/PMID 去重，无标识符核对标题作者年份。
- 逐条标明全文、摘要或仅元数据。无法访问全文时不编造效应量、调整方案和队列细节。

## 判断实质差异

用矩阵逐项比较当前想法与最相近论文：人群 / 暴露及窗口 / 比较 / 结局及随访 / 方法 / 真正差异 / 待验证。

仅换一个比值指标并研究相同死亡结局，通常是形式变化；推荐时需解释独立临床用途或测量优势。没找到直接论文既可能是检索缺口，也可能是数据不支持，要和数据证据一起判断。

官方入口：[PubMed User Guide](https://pubmed.ncbi.nlm.nih.gov/help/)；[NLM E-utilities](https://www.nlm.nih.gov/dataguide/eutilities/utilities.html)。创建时于 2026-10-09 核对；每次使用重新检索，不把创建日期当文献截止日期。

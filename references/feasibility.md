# 数据可行性预检

以 draft.md 原始定义为审计对象。先列出草案要求 → 数据来源/构造 → 验证方法 → 状态的映射，关键缺失定义不得默默填补。预检发现需要改定义时，原方案和备选方案分别报告；备选查询通过不能当原方案通过。原稿给出的预计样本量、缺失率和事件率均待实际核查。

## 核查环境与变量

记录实际数据库版本、schema/项目/目录、模块、方言、源表与派生表版本。通过 information_schema、元数据或 CSV 表头验证结构，使用现有客户端，不自动安装数据库、全量导入或创建物化表。

| 数据需求 | MIMIC-IV 查找入口 | 必须核查 |
|---|---|---|
| 人口学/住院/ICU | hosp.patients、admissions；icu.icustays | subject_id、hadm_id、stay_id 粒度、重复就诊 |
| 检验 | hosp.labevents、d_labitems | 项目字典、单位、时间、缺失 hadm_id |
| 床旁记录 | icu.chartevents、d_items | 同义项目、测量频率、异常值、单位 |
| 药物/干预 | prescriptions、emar/emar_detail、icu.inputevents/procedureevents | 医嘱与实际给药不同；剂量、速率、途径、起止时间 |
| 诊断/操作 | diagnoses_icd、procedures_icd 及其字典 | ICD-9/10 分开；出院编码不保证发病时间 |
| 临床概念 | 官方代码 sepsis、organfailure、score、treatment 等 | 定义、依赖、代码/数据库版本、窗口 |
| 病历/影像/急诊 | Note、CXR、ED 独立数据集 | 单独权限、覆盖范围、连接产生选择偏倚 |

表格只是入口，不能代替实际 schema。枚举字典并记录 label、itemid、单位和选择依据，不凭一次字符串匹配声称定义完成。优先复用核验后的概念代码，也核查当地派生表确实按该定义生成。

[官方 concepts](https://github.com/MIT-LCP/mimic-code/tree/main/mimic-iv/concepts) 主目录使用 BigQuery SQL，仓库另有 PostgreSQL/DuckDB 版本。记录所用提交/版本和修改，官方定义也需验证适配性。

## 最小查询链

1. 队列：逐项纳排，报告各步独立患者、住院、ICU stay 数；声明分析单位及是否只保留首次。首次按时间排序，不按 ID 大小。各指标复用同一队列定义。
2. 暴露：指定窗口内构建单位级暴露，报告组别人数和无法分类人数。无记录可能是未测量/系统覆盖不足，不直接当未暴露。
3. 结局：报告事件、可观察人数、各组事件、随访和删失/出院处理。未知与无事件分开，住院结局不能冒充完整 28/90 天结局。
4. 质量：关键变量在指定窗口的覆盖人数、缺失分子/分母及比例，按组核查；必要时检查测量频率、单位、分位数和异常值，保留证据再讨论处理。
5. 连接/时序：主要 join 前后核查单位数与行数。事件表先按目标单位及窗口聚合，避免多对多放大；核查暴露、协变量相对时间零点和结局的位置。

每条查询保留 SQL、参数、执行状态/时间、数据版本及聚合结果。核心校验：纳排后人数不增加；互斥组与未分类组总和等于分析人数；事件数不超过适用分母；缺失率在 0–1；每单位行数符合定义。可用小型 assert 自检，不能反推或编造数量。

## 时间与偏倚

- SQL 前写清时间零点、资格窗口、暴露/协变量窗口、结局观察起点和随访终点。
- 用入 ICU 后 24 小时指标预测死亡时处理窗口内死亡/出院；采用 landmark 必须声明只适用于存活至该时点者，或选择适合早期事件的时变设计，不能无说明排除早亡。
- 住院期间是否接受治疗的死亡比较可能有不死时间偏倚；需定义资格时点、治疗策略/宽限期及恰当时间分析，不能声称加入回归变量即可消除。
- 预测信息须在真实使用时点可得，核查记录时间与可用/存储时间差别。患者级拆分避免跨训练验证集；外部数据库存在不等于已完成外部验证。
- 根据临床机制区分混杂、中介和碰撞变量，不自动调整全部变量或用单因素 p 值筛混杂；核心混杂不可测时明确因果解释限制。

## MIMIC 特有事项

- 同患者日期偏移一致，可计算患者内间隔；不同患者偏移后年份不可直接当真实历年比较。跨模块核查患者及日期对齐；历年问题查 anchor_year_group，不声称精确真实年份。[数据说明](https://physionet.org/content/mimiciv/3.1/)
- 年龄与高龄去标识、院外死亡和随访上限按实际版本文档核查，不能由偏移年份直接减出生年份，不能假定死亡完整可见。
- 重复住院、ICU 再入和医院/ICU 起止不同，按问题处理重复及相关性。缺尿量不代表正常，缺护理记录不代表无治疗，处方不等于给药，概念表名字不等于金标准。
- demo/小样本仅验证结构和 SQL，不推断全库规模、频率或缺失率。

## 判定

总人数多不代表事件、暴露重叠或精确度足够。结合目标效应/精度、组别不平衡、候选参数和随访评估，不把每变量 10 个事件或统一缺失率当通用门槛。正式样本量计算需列假设，未做则注明。

能取到数据仅说明初步可行。核心变量不存在、时序不辨、事件不足或缺失严重时，给出可核验原因，提出有临床意义的改题或建议放弃。
